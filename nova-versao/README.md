# Agenda Pro — demonstração

Protótipo estático responsivo de agenda para profissionais de beleza. Abra `index.html` em navegador ou hospede a pasta em servidor estático.

Funcionalidades: clientes, serviços, agendamentos, filtro por data, conflito de horários e estados concluído/cancelado. Dados ficam em localStorage, sem login ou sincronização.

**Não usar dados reais de clientes.** Ainda faltam autenticação, isolamento de contas, backend, validação do servidor, backups, LGPD e testes automatizados. A versão PHP original permanece na branch master.
